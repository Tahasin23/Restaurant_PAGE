# Juniper & Stone

A modern, responsive restaurant website with a digital menu
and restaurant owner management workspace.

## 🌐 Live Website

https://tahasin23.github.io/Restaurant_PAGE/

## Features

- Responsive restaurant homepage
- Digital food menu
- Menu category filtering
- Owner login demonstration
- Restaurant dashboard
- Add, edit and delete food items
- Food availability management
- QR code menu generator

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages
